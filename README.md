# Sistemi e Reti - Classroom 3D Model Website

This is a school group project developed by a team of 4 students for the "Sistemi e Reti" course. The main goal of the project was to create a 3D model of a classroom and embed it into a functional web page.

## Description
The project consists of a simple website that integrates a 3D model of a classroom environment. Users can view and interact with the model directly in the web browser. The layout is designed using basic web technologies to ensure the embedded asset displays correctly.

## Repository Structure
- `index.html` — Main webpage structure.
- `style.css` — Basic styling and layout positioning.
- Assets — Folder containing the 3D model files or integration scripts.

## Tech Stack
- HTML5
- CSS3
- JavaScript (for model integration/embedding)

## How to Run Locally
1. Clone or download this repository to your computer.
2. Open the `index.html` file in any modern web browser.
