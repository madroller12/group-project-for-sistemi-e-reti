# Interactive 3D Classroom Web Integration

A collaborative web development project designed and implemented for the "Sistemi e Reti" course. This application features an embedded, interactive 3D model of a classroom environment, demonstrating modern web technologies, responsive layout design, and smooth 3D asset rendering.

## Project Overview
The primary objective of this project was to design a detailed 3D model of a classroom and successfully integrate it into a functional website. Developed by a team of 4 students, the project focuses on achieving a seamless user experience, fast asset loading times, and a highly responsive user interface.

## Features
- **3D Environment Embedding:** Interactive rendering of a classroom layout directly within the web browser.
- **Responsive Web Design:** The layout automatically adjusts to ensure visual consistency across desktop and mobile devices.
- **Team Collaboration:** Built using structured workflows to successfully merge design assets and web development logic.
- **Performance Optimization:** Compressed 3D assets to ensure fast page loading without sacrificing model fidelity.

## Tech Stack
- **HTML5 & CSS3:** Semantic layout, custom styling, and responsive grid/flexbox configurations.
- **JavaScript:** Client-side scripting for interactive elements, navigation logic, and rendering control.
- **3D Rendering / Integration:** WebGL-based integration (Three.js / Spline / Embedded Viewer) for smooth 3D object manipulation.

## Deployment & Execution
To view and test the project locally:
1. Clone or download this repository.
2. Ensure all 3D asset paths (e.g., .obj, .gltf, or iframe links) are correctly configured in the source code.
3. Open `index.html` in any modern web browser.
